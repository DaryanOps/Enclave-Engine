# Enclave Engine
A search engine built in Rust with designed to handle efficient text indexing, autocomplete, typo-tolerant querying.

# Core Feautures
 **Autocomplete**.
 **Multi-word recognition**.
 **Snippets**.
 **BM25 Ranking**.

# Rust was chosen for its efficiency and memory safety.
Tokio: async runtime
Axum: web framework
